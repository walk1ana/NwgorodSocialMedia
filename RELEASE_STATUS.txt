NewGorod — friends feature release

Added:
- Dedicated Friends navigation page.
- Search registered profiles by display name.
- Send friend requests.
- Incoming and outgoing request lists.
- Accept and reject requests.
- Mutual friends list and remove-friend action.
- Friend count in the profile.
- Supabase RLS migration for friend_requests.

Required before use:
1. Run supabase/migrations/202611240002_friend_requests.sql in Supabase SQL Editor.
2. Deploy the complete project folder to GitHub Pages.
3. Test with two separate accounts.

The feature has been syntax-checked locally. It has not been tested against the user's live Supabase project or in a real browser session. The friends UI depends on the second SQL migration.
