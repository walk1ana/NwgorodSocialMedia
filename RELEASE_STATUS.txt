NewGorod — friends and direct messages

Added:
- Dedicated Friends navigation page.
- Search registered profiles by display name.
- Send friend requests.
- Incoming and outgoing request lists.
- Atomic accept and reject request handling.
- Mutual friends list and remove-friend action.
- Friend count in the profile.
- Direct messages with accepted friends and Supabase Realtime updates.
- Supabase RLS migrations for friend requests and private chats.

Required before use:
1. Ensure the existing Supabase project has the `public.profiles` table.
2. Run `supabase/migrations/202611240002_friend_requests.sql` and then `supabase/migrations/202611250001_friend_messages.sql` in Supabase SQL Editor.
3. Deploy the complete project folder to GitHub Pages.
4. Test requests and messaging with two separate accounts.

JavaScript syntax, unique HTML ids, patch whitespace checks and local browser rendering are verified. The changes have not been tested against the live Supabase project or with two accounts; run the applicable SQL and deploy the updated files before use.

Audio/video calls:
- Run `friend_calls.sql` in Supabase SQL Editor after the `public.friend_requests` table exists.
- Enable private Realtime channels and disable public access in Supabase Realtime settings.
- Both users must be online, signed in, and allow microphone/camera access over HTTPS.
- This prototype uses a public STUN server only; some networks will require a TURN server.
