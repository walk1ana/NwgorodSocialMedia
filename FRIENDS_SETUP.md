# NewGorod - включение раздела «Друзья»

В этой версии добавлен отдельный раздел с поиском жителей, входящими и отправленными заявками, принятием/отклонением заявок, списком друзей и удалением из друзей.

## Важно: сначала добавь таблицу в Supabase

Первоначальная миграция создаёт подписки (`follows`), но не дружбу. Для нового раздела нужна отдельная таблица `friend_requests`, созданная в Supabase Dashboard отдельным SQL-запросом.

1. Открой Supabase Dashboard -> SQL Editor -> New query.
2. Выполни SQL для создания таблицы `friend_requests` и её RLS-политик.
3. Убедись, что результат — Success.

## Опубликуй сайт

Загрузи файлы проекта в GitHub Pages. Включая обновлённые `index.html`, `styles.css`, `supabase-integration.js` и `sw.js`.

## Проверка

Лучше проверить двумя разными тестовыми аккаунтами:

1. В аккаунте A найди по имени аккаунт B и нажми «Добавить».
2. Выйди и войди в аккаунт B - заявка должна появиться во «Входящих заявках».
3. Нажми «Принять» - аккаунты должны появиться друг у друга в «Моих друзьях».
4. Проверь удаление из друзей.

Поиск выполняется по `profiles.display_name`. Он ищет только зарегистрированные аккаунты, которые уже имеют профиль в Supabase.

## Безопасность

Доступ к заявкам ограничен RLS: читать их могут только отправитель и получатель; отправлять заявку можно только от своего аккаунта; принимать/отклонить её может только получатель. Не добавляй `service_role` или пароль базы данных в клиентский код.
